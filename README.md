# Gemini Pro 国内怎么开通：官方路径卡在哪、国内支付怎么过、代订价格与续费风险怎么权衡

搜这个问题的人，卡点通常不在“Gemini 到底好不好用”，而在最后一步——付款。

Google 官方的支持国家/地区清单里，中国大陆那一栏只标了一句 “Workspace only”，意思是只对 Google Workspace 企业账号开放，普通个人账号不在支持范围内。香港不在清单里，台湾和澳门在列。Gemini 按 IP 判地区，用大陆网络打开会直接提示不支持所在地区。订阅页也只有美元定价，没有人民币方案。

所以“国内怎么开通”其实是两个问题叠在一起：怎么让账号处在 Google 认可的地区，以及怎么把钱付出去。下面按从官方到第三方的顺序捋一遍，每条路都告诉你卡在哪、代价是什么。

## 先看清官方现在到底卖什么

很多人搜“Gemini Pro”，但 Google 现在面向个人的付费档位叫 **Google AI Pro**，订阅页上不一定出现“Gemini Pro”这四个字。搞清楚档位，才不至于买错。

| 官方档位 | 价格 | 主要差异 |
| --- | --- | --- |
| Free | US$0 | Gemini 3.6 Flash 全量使用，3.1 Pro 只有有限额度，15GB 存储 |
| Google AI Plus | US$4.99 / 月 | 额度约 2 倍，400GB 存储 |
| Google AI Pro | US$19.99 / 月 | 额度约 4 倍，完整访问 Gemini 3.1 Pro（100 万 token 上下文），Deep Search，5TB 存储 |

官方价格和档位调整得挺勤，进订阅页看到的数字才算数。对大多数个人用户来说，中间那档 US$19.99 就是目标。

## 官方直订的两个卡点

### 卡点一：付款资料的国家/地区

Google 账号可以挂多个付款资料，每个付款资料有唯一的法定地址，而地址一年只能改一次。如果你的付款资料法定地区是中国大陆，点订阅时会看到“此账号无法订阅 Google AI 方案”。

社区里流传的处理办法是把付款资料切出去：进入「付款与订阅 → 设置 → 支付资料」，新建一个支持地区的付款资料，再把默认资料切过去。另一步是在手机 Google Play 的「账号和设备偏好设置」里，把国家/地区改成支持地区。这两步都属于用户自述经验，不是 Google 官方教程，能不能过要看账号状态。

### 卡点二：卡本身

这一环最玄学。论坛里跑通的案例包括工行 Visa、招行 Visa、农行 Visa、民生和中信的 AE 卡，也有人靠美区 PayPal 加国内 Visa 过的。失败的组合往往很一致：国内卡 + 大陆节点 + 付款资料留在中国。

同一个问题下经常能看到“我一次就过”和“怎么都绑不上”并排出现，说明风控是综合判断发卡地区、账单地址、IP 和账号历史，不是单纯看卡。

虚拟卡是另一条被大量讨论的路。美国卡、小红卡这类，闲鱼上十几块到十几美元能买到，有人说一次成功，也有人反馈开通几天后失效、需要重新换卡。用它的成本不只在买卡那一下，而在后续维护。

> 学生优惠值得单独提一句：官方确实有面向在读学生的免费方案，但它需要真实的在读身份，Google 会做核验。市面上有“代认证”服务，价格几十元，通过之后短时间内确实能用——但身份核查一旦被推翻，订阅会被取消，不建议把它当成长期方案。

如果不想在这些环节上反复试，还有一种做法是让第三方平台替你完成支付。这就是 WildAI（BeWild.ai）这类服务存在的原因，下面单独说。

## 第三方代订：把支付这一步外包出去

WildAI 的前身是野卡（WildCard），2024 年 9 月 20 日以 WildAI 这个名字重新上线。它不训练模型，做的事很具体：帮国内用户把海外 AI 服务的订阅费付出去。

跟“买成品号”最大的区别是账号归属。它走的是在自己的账号上开通订阅，而不是把别人的号卖给你。对于一个已经积累了大量对话记录的 Google 账号来说，这一点比省几块钱重要得多。

流程大致是这样：进平台官网，选服务和时长，填上要开通的账号邮箱，提交支付信息，微信或支付宝扫码付款，平台在对应账号上完成开通。老用户那边还有一段历史：野卡时期的账户余额，后来是通过兑换订阅来处理的，平台发过邮件通知，限期 45 天、只能兑换一次。

## 代订的真实风险，是续费

价格和开通都算顺利，容易出问题的是第二个月、第三个月。

一位博主公开记录过完整的翻车过程：他在 WildAI 买的三个月 ChatGPT Plus，第一次自动续费成功，第三次时 OpenAI 明确提示付款失败，原账单没付出去。等客服超过一小时后确认，是平台用来向 OpenAI 自动续费的那个付款方式失效了，未完成的部分退了 150.69 元。他重新下单，订单一度失败，用页面上的“继续任务”才跑完，OpenAI 那边旧账单作废、生成了新的 20 美元已支付账单。

同一位博主还记录过另一位用户的遭遇：三个月套餐没有按期自动续费，新买的两月套餐订单显示完成但账号仍是免费版，两笔订单最后分别以退款或退款方案收尾。另外他也收到过平台提示，要求重新上传当前有效的账号 Session 才能继续处理剩余月份的续订。

这些案例说明一件事：第三方代订的故障点不在你的账号，而在平台替你付给官方的那条通道。平台的处理结果是退款加补偿，算是有兜底，但中间会有几天用不上。买长周期套餐之前，最好把这个成本算进去，别把它当成“一次买完就三个月无事”。

## 如果你要的是 API，订阅解决不了

订阅和 API 是两条独立的线。Gemini Pro 订阅给的是网页端和 App 的使用权，不等于你能拿到 API Key。

开发者这条路可选的做法有几个：Google AI Studio 有基础免费额度，用个人 Google 账号登录就能创建 API Key，够调试用；再往上走是 Vertex AI，走的是 IAM 鉴权和 Service Account，工程复杂度明显更高；还有一种是聚合网关，把 Google 的协议转成 OpenAI 兼容格式，代码里只需要改 `base_url` 和 key，不用动现有架构。

国内服务器直连官方端点会遇到跨境路由抖动，容易超时。自己搭反代也能跑，Cloudflare Workers 便宜但长文本流式响应容易断，海外轻量服务器稳一些，成本大概几十元一个月。

只是想让模型能力可用、又不在意具体是哪家的，豆包、Kimi、通义、DeepSeek 都能手机号注册直接开，没必要为这一件事绕一大圈。

## 怎么选，看你的实际情况

只想在网页上日常和 Gemini 对话，而且手上已经有能过的国际卡、也有稳定的海外网络环境——那就走官方，最省事也最便宜，没有中间人。

试过几次都被拒、不想再研究账单地址和付款资料的——第三方代订就是为这种情况准备的，代价是每月多花几美元，以及接受续费可能出岔子。

需要长期稳定、且用量很大的——先想清楚你到底是需要网页订阅还是 API 额度，这两件事的解法完全不同，别花了两份钱只解决一个问题。

## 几个高频问题

**注册时用大陆手机号可以吗？** Google 通常要求手机号验证，用非大陆号码的账号稳定性更好，但大陆号码在部分情况下也能走通，这一步不一定是硬门槛。

**开通之后能不能马上切回大陆网络？** 立刻切回容易触发重新验证，稳妥的做法是正常用几天之后再调整网络。

**WildAI 上的价格比官方贵，值得吗？** 单看数字不值得。它卖的是免去开卡费、充值手续费和反复试卡的时间成本。你如果已经有能稳定付款的渠道，那这几十块的溢价确实没必要付。

**学生免费方案和代订怎么选？** 你如果确实是在读学生、能通过官方核验，直接用官方学生方案，那是最划算的；身份本身不满足的话，走第三方代订比买“代认证”更安全。

不管走哪条路，先确认当前价格再付款——官方的档位和第三方平台的报价都在变，页面上显示的数字永远比文章里写的更准。想省掉自己试卡的环节，可以直接从带邀请码的入口进去看看当前的套餐和价格。
